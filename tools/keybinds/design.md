# Пресет управления Fear Nightfall

Пресет рассчитан на Fear Nightfall 1.2.0, Minecraft 1.20.1, Forge 47.4.8 и Java 17. Базовые 34 назначения Minecraft сохранены. Книга квестов открывается физической клавишей под Esc (`grave.accent`, на US-клавиатуре `~`). Рюкзак открывается на B, аксессуары на H, атлас на I, меню голосовой связи на V, микрофон на M. Наклоны перенесены на J и K, шаг наклона на квадратные скобки, модификатор Leaning Or Not на пятую кнопку мыши. Ползание назначено на Z, переключатель ползания на Alt+N. Клавиши мыши 6–8 используются для зума рельсотрона, меню Structure Gel и зарядки AED. Для части дополнительных действий нужен цифровой блок.

`registered-keys.txt` содержит только строки назначений, которые сохранил ранее запущенный клиент. Список из 223 строк совпал с выгрузкой текущего установленного клиента, включая значения по умолчанию. База данных поставки — манифест `5cff71d48dc15afe8f1d16e345bf1ec17dc5f71d`, SHA-256 `f6b4ad81ac688cdd450c18ab2bef8aeee0afa5cdb2de9bc9bcecc82e14fb104e`. SHA-256 всех 1688 файлов установленной сборки совпали с манифестом. Имена и значения из выгрузок хранятся без прочих личных настроек.

Проверка вне игры учитывает совпадение клавиш, модификаторов Forge и пересечение контекстов. Учтены `KeyMapping.same`, `Options.setForgeKeybindProperties` Forge, назначения `ModKeyBindings` Hexerei 0.4.2.3 и интерфейсные действия JEI 15.74.0.232 (`InternalKeyMappings`, `ForgeJeiKeyMappingBuilder`). Узкие режимы JEI объединены в один GUI-контекст для более строгой проверки внутри JEI. Атака, применение предмета и выбор блока относятся к игровому вводу. Клики в интерфейсе JEI могут использовать те же кнопки. Остальные непроверенные контексты считаются общими. Единственное намеренное общее назначение — Left Shift для приседания и Carry On. Мод регистрирует это действие через `ConflictFreeKeyMapping` и использует удержание Shift при взаимодействии с блоком или сущностью. Назначения Leaning Or Not проверены по `LeaningOrNotClientEvents`, который читает объект переназначаемой клавиши.

Проверка моделирует доступные действия по сохранённому инвентарю и разобранным контекстам. Прямые обработчики ввода за пределами реестра, аппаратные клавиши и переназначения самого игрока в эту проверку не входят. Для проверки пресета Minecraft не запускали.

Изменения раскладки вносятся в `layout.json`. Пересборка и проверка:

```sh
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py
```

`publish.yml` выпускает изменения пресета на GitHub через `pack-latest`. Публикация сверяет размер и SHA-256 сохранённых игровых архивов с GitHub, первым загружает отдельный архив пресета и карточку с новой ревизией, затем заменяет публичный манифест. Путь и SHA-256 пресета сверяются повторным скачиванием. Для изменений состава сборки действует обычный процесс из README.
